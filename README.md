# NexaLytix Landing Page (`nexaa`)

A standalone, zero-dependency single-page HTML5/CSS3 marketing landing page (`nexaa.html`) for **NexaLytix** (*"Connecting Data, Inspiring Growth"*), featuring a dark gradient theme and responsive layout.

---

## 1. Executive Summary & Purpose
`nexaa` provides a lightweight, instant-loading brand landing page for a data analytics and growth consultancy (`NexaLytix`).

## 2. Architecture & Layers
- **Markup & Presentation (`nexaa.html`)**: Self-contained HTML5 document with embedded CSS3 dark-mode gradients, typography, and responsive viewport configuration.

## 3. Getting Started
Open `nexaa.html` directly in any browser or deploy to any static host (Vercel, Netlify, GitHub Pages, Cloudflare Pages).

## 4. Business Value & Growth Opportunities
- **Zero-Cost Static Deployment**: Deployable in seconds as a lead-capture landing page; can be wired to `input-to-sheets-app` or `lead-finder-nexus-tool` webhooks to collect client inquiries.
